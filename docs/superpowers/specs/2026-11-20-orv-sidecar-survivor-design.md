# Design Document: Star Stream — Side-Car Survivor (Scenario #1: Proof of Value)

**Date:** 2026-11-20  
**Engine:** Godot 4.7.2 (GDScript, 2D Pixel Art)  
**VFX Pipeline:** `patch-gg/pixelfx` (exported Sprite Sheets PNG + JSON)  
**UI Language:** ภาษาไทย (Thai)  

---

## 1. Intent & The Why

ผู้เล่นต้องการสร้างเกมแอ็กชัน 2D Pixel Art มุมมองด้านข้างในจักรวาล *มุมมองนักอ่านพระเจ้า (Omniscient Reader's Viewpoint — ORV)* โดยรับบทเป็น **ผู้โดยสารธรรมดาในอีกตู้หนึ่งของรถไฟใต้ดินสาย 3** (ไม่ได้อยู่ในกลุ่มของคิมดกจา) ที่ต้องเอาชีวิตรอดใน **บทละครหลักที่ 1 — พิสูจน์คุณค่า (Proof of Value)** ด้วยระบบเดียวกับในเรื่อง: สุ่มคุณลักษณะเฉพาะ (Personal Attribute), อัปสเตตัสด้วยเหรียญ, ซื้อของ/สกิลจากถุงโดแกบี, รับสปอนเซอร์จากกลุ่มดาว, ใช้สกิลพร้อม VFX จาก `pixelfx` และปิดท้ายด้วยการเลือกกลุ่มดาวผู้สนับสนุน (Sponsor Selection)

---

## 2. Goals, Non-Goals, and Anti-Goals

### Goals
- **Complete, High-Polish Scenario #1:** โฟกัสเฉพาะ **บทละครหลักที่ 1 (ตู้รถไฟใต้ดิน 3 ตู้เชื่อมต่อกัน)** ให้แน่น เล่นซ้ำสนุก และครบเครื่องตั้งแต่หน้าสุ่มคุณลักษณะเฉพาะ → คัตซีนเปิดหน้าต่าง Star Stream → การต่อสู้/สำรวจในตู้รถไฟ → เคลียร์บทละคร (2 เส้นทาง + Sub/Hidden Scenario) → Sponsor Selection & หน้าสรุปผล
- **Randomized Personal Attributes (คุณลักษณะเฉพาะ):** สุ่มคุณลักษณะเฉพาะก่อนเข้าด่าน (กดสุ่มใหม่ได้) แบ่งระดับความหายาก **ทั่วไป / หายาก / วีรชน** ซึ่งเปลี่ยนสเตตัสเริ่มต้น อาวุธ/ไอเทมติดตัว และความสามารถพิเศษ
- **Snappy 2D Side-Scrolling Combat:** เดินซ้าย-ขวา, กระโดดหลบ, พุ่งตัวหลบซ้าย-ขวา (Dash + i-frames + Perfect Dodge), โจมตีคอมโบ, กดใช้สกิลและไอเทม พร้อม Hit-Stop, Knockback และ Screen Shake
- **Authentic ORV Core Systems:** ครบทั้ง 5 เสาหลัก — ตัวละคร & Attribute Window (อัป STR/PHY/AGI/MAG ด้วยเหรียญ), เหรียญ & สปอนเซอร์จากกลุ่มดาว, เควส (Main/Sub/Hidden Scenario), สกิล (`pixelfx` VFX), ไอเทม & ถุงโดแกบี (Dokkaebi Bag)

### Non-Goals
- ยังไม่สร้างบทละครที่ 2 และ 3 ในเวอร์ชันนี้ (โฟกัสเฉพาะบทละครที่ 1 ให้สมบูรณ์ที่สุด)
- ไม่มี Multiplayer / Voice Acting / ระบบหลาย Save Slot
- ไม่ใช้ภาพ สไปรต์ หรือโลโก้ที่มีลิขสิทธิ์จากเว็บตูน/นิยายต้นฉบับ

### Anti-Goals
- การต่อสู้ที่ไร้น้ำหนัก ไม่มี hit-stop หรือเอฟเฟกต์ดูแปะลอย
- พิกเซลเบลอ หรือฟอนต์ภาษาไทยอ่านไม่ออก/สระซ้อน
- หน้าต่างข้อความยาวจนขัดจังหวะแอ็กชัน

## 3. Technical Constraints & Architecture

- **Engine:** Godot `4.7.2.stable` (GDScript)
- **Hybrid Rendering (Crisp Pixel Art + HD Thai UI):**
  - หน้าต่างหลักขนาด `1280x720` (`Stretch Mode: canvas_items`, `Aspect: keep`) สำหรับ UI หน้าต่าง Star Stream และฟอนต์ภาษาไทยให้คมชัดระดับ HD
  - โลกเกมทั้งหมด (ตัวละคร, ตู้รถไฟ, ศัตรู, `pixelfx` VFX) รันภายใน `SubViewport` ขนาด `480x270` ผ่าน `SubViewportContainer` ที่ตั้ง `TEXTURE_FILTER_NEAREST` เพื่อให้พิกเซลและเอฟเฟกต์คมชัดเป็นกริดพิกเซลแท้ 100%
- **Thai Font:** คัดลอกฟอนต์ TTF ที่รองรับภาษาไทยครบ (เช่น `Thonburi` / `Tahoma` / `Ayuthaya` หรือฟอนต์ระบบ macOS ที่รองรับสระ/วรรณยุกต์ไทยสมบูรณ์) มาไว้ใน `res://assets/fonts/` และตั้งเป็น default theme font
- **`pixelfx` Pipeline:**
  - Clone `https://github.com/patch-gg/pixelfx` ไว้ที่ `/Users/mac/Desktop/GAME_Project/tools/pixelfx` (นอก `godot_project/`)
  - Render เอฟเฟกต์ที่เลือกด้วย `node tools/render.mjs <effect-id> --sheet --opts '...'` แล้ว copy `.png` + `.json` เข้า `res://assets/vfx/`
  - โหลดด้วย `VfxManager` ใน GDScript ที่อ่าน `meta.pixelfx` (`fps`, `loop`, `pivot`, `frame size`) เพื่อสร้าง `SpriteFrames` พร้อม `TEXTURE_FILTER_NEAREST` อัตโนมัติ
- **Autoload Singletons:** `GameState` (ข้อมูลผู้เล่น, Attribute, สเตตัส, เหรียญ, คลัง, สกิล), `ScenarioManager` (เควสหลัก/รอง/ลับ, ตัวจับเวลา, ข้อความกลุ่มดาว), `VfxManager` (สปอว์นเอฟเฟกต์ `pixelfx`), `SfxManager` (เสียงสังเคราะห์ retro WAV)

## 4. Randomized Personal Attributes (คุณลักษณะเฉพาะตอนเริ่ม)

ตอนเริ่มเกม หน้าต่าง Star Stream จะสุ่มคุณลักษณะเฉพาะ 1 อย่าง (กดปุ่ม **"สุ่มใหม่"** ได้ไม่จำกัดก่อนกด **"เข้าสู่บทละคร"**):

| คุณลักษณะเฉพาะ | ระดับ | โอกาสออก | สเตตัสเริ่มต้น (STR/PHY/AGI/MAG) | อาวุธ & ไอเทมติดตัว | ความสามารถติดตัว (Passive) |
|---|---|---|---|---|---|
| **พนักงานออฟฟิศผู้เหนื่อยล้า** | ทั่วไป (Common) | 35% | 1 / 2 / 1 / 1 | ร่มพับ + น้ำยารักษา x1 | เริ่มเกมด้วย +50 เหรียญ |
| **อดีตนักกีฬาชมรมดาบ** | หายาก (Rare) | 22% | 3 / 1 / 2 / 1 | ดาบไม้ไผ่พกพา | โจมตีปกติแรงขึ้น +20% |
| **นักวิ่งมาราธอนตอนเช้า** | หายาก (Rare) | 22% | 1 / 2 / 3 / 1 | ร่มพับ + หินมานา x1 | Dash คูลดาวน์เร็วขึ้น 25%, Perfect Dodge ได้เหรียญ x1.5 |
| **อาสาสมัครกู้ภัย** | หายาก (Rare) | 15% | 1 / 3 / 1 / 2 | ท่อเหล็ก + ชุดปฐมพยาบาล x2 | ไอเทมฟื้น HP แรงขึ้น +40% |
| **นักอ่านนิยายวันสิ้นโลก** | วีรชน (Hero) | 6% | 2 / 2 / 2 / 3 | มีดพกเหล็กกล้า + หินมานา x1 | เห็นออร่าคำใบ้ "กล่องแมลง" ทางลับชัดขึ้น + กลุ่มดาวสปอนเซอร์เหรียญง่ายขึ้น +30% |

## 5. Gameplay, Controls & ORV Systems

### Controls
| Action | Primary Key | Alt Key |
|---|---|---|
| เดินซ้าย / ขวา | `A` / `D` | `Left` / `Right` |
| กระโดด | `Space` | `W` / `Up` |
| พุ่งตัวหลบ (Dash + i-frames) | `Shift` | `K` |
| โจมตีปกติ (3-hit combo) | `J` | `Z` / Left Click |
| สกิล 1 / 2 / 3 | `1` / `2` / `3` | `U` / `I` / `O` |
| ไอเทมด่วน 1 / 2 | `Q` / `E` | — |
| โต้ตอบ / สำรวจ / เก็บของ | `F` | — |
| หน้าต่างตัวละคร (Attribute & Inventory) | `Tab` | `C` |
| ถุงโดแกบี (Dokkaebi Bag) | `B` | — |

### Character & Coin Stat Upgrades
- **4 Core Stats:** STR (`ATK = WeaponATK + STR * 3`), PHY (`MaxHP = 80 + PHY * 20`), AGI (ความเร็วเดิน + ลดคูลดาวน์ Dash + โอกาสคริ), MAG (`MaxMP = 40 + MAG * 15` + ความแรงสกิล)
- **Upgrade Cost:** `100 * current_level` เหรียญ (กดอัปได้ตลอดเวลาในหน้าต่างตัวละคร พร้อม VFX ออร่าอัปเลเวลจาก `pixelfx`)

### Skills & `pixelfx` VFX
1. **ฟันกวาดฉุกเฉิน (Desperate Slash)** — มีตั้งแต่เริ่ม (MP 10, CD 2.2s): ฟันกว้างผลักศัตรู
2. **ก้าววายุ (Wind Step Slash)** — ซื้อใน Dokkaebi Bag (180 เหรียญ, MP 15, CD 3.8s): พุ่งฟันทะลุศัตรู
3. **คลื่นกระแทกพลังเวท (Mana Burst)** — ซื้อใน Dokkaebi Bag (220 เหรียญ, MP 20, CD 5.0s): ระเบิดพลังเวทรอบตัวผลักศัตรู
4. **เกราะพลังเวท (Magic Barrier)** — ซื้อใน Dokkaebi Bag (200 เหรียญ, MP 18, CD 6.5s): โล่กันดาเมจชั่วคราว
- **VFX จาก `pixelfx`:** Slash, Dash trail, Hit spark, Arcane/Mana burst, Holy/Shield aura, Fire bomb explosion, Coin pickup sparkle, Level-up aura

### Items & Dokkaebi Bag
- **อาวุธ:** ร่มพับ (ATK 8), ท่อเหล็ก (ATK 12), ดาบไม้ไผ่พกพา (ATK 14), มีดพกเหล็กกล้า (ATK 18 — ซื้อได้ 160 เหรียญ), ดาบสั้นคริสตัล (ATK 26 — ซื้อได้ 320 เหรียญ)
- **ไอเทมกดใช้:** น้ำยารักษา (+50 HP — 70 เหรียญ), ชุดปฐมพยาบาล (+90 HP — 120 เหรียญ), หินมานา (+45 MP — 70 เหรียญ), ระเบิดเพลิงโดแกบี (ปาทำดาเมจไฟวงกว้าง — 110 เหรียญ)
- **ไอเทมเฉพาะบทละคร:** กล่องแมลงของเด็กน้อย (เก็บได้ในตู้รถไฟที่ 3 สำหรับเส้นทางไม่ฆ่าคน)

### Scenario #1 Layout & Quest Flow (3 Connected Subway Cars)
- **ฉาก:** ตู้รถไฟใต้ดิน 3 ตู้เชื่อมต่อกัน (`Car 1` → `Car 2` → `Car 3`, ความกว้างรวม ~1,600 px) มีไฟกระพริบ, ประตูรถไฟ, เบาะนั่ง/กระเป๋าที่กระโดดข้ามได้, หน้าต่างเห็นอุโมงค์มืด
- **เปิดฉาก:** โดแกบีปรากฏตัวลอยกลางตู้ 1 → หน้าต่างสีฟ้า `[ บทละครหลัก #1 — พิสูจน์คุณค่า ]` เด้งขึ้นมา:
  - *เงื่อนไขเคลียร์:* กำจัดสิ่งมีชีวิตอย่างน้อย 1 ตัว
  - *เวลาจำกัด:* 180 วินาที
  - *รางวัล:* 300 เหรียญ
- **ศัตรูและจุดโต้ตอบในขบวน:**
  - **ตู้ 1 (จุดเริ่มต้น):** ผู้โดยสารตื่นตระหนก, จุดเก็บอาวุธสำรอง, อันธพาลคลุ้มคลั่ง 2 คน
  - **ตู้ 2 (กลางขบวน):** **Sub-Scenario "ช่วยผู้โดยสารที่ถูกต้อนมุม"** — ช่วย NPC หญิงสาวจากอันธพาล 2 คน (+150 เหรียญ + น้ำยารักษา) และผู้โดยสารที่อัปสเตตัสแล้ว (ศัตรูสายพุ่งชน)
  - **ตู้ 3 (ท้ายขบวน):**
    - **มินิบอสประจำตู้:** *"หัวหน้าแก๊งคลุ้มคลั่ง (ผู้ถูกกลุ่มดาวมืดกระตุ้น)"* ที่มีท่าพุ่งแทงและฟันกวาดพร้อม telegraph
    - **ทางลับ (Hidden Scenario "ผู้ไม่ยอมจำนนต่อความบ้าคลั่ง"):** กด `F` สำรวจกระเป๋าเป้เด็กน้อยที่มุมตู้ 3 เพื่อหา **กล่องแมลง (ตั๊กแตน)** แล้วเลือกกำจัดแมลงในกล่อง → เคลียร์บทละครที่ 1 ทันทีโดยไม่ต้องฆ่าคน + รับโบนัส **+250 เหรียญ** และข้อความกลุ่มดาวชื่นชม!
- **ตอนจบบทละครที่ 1:**
  - เมื่อเคลียร์เงื่อนไข (ไม่ว่าจะทางสู้หรือทางลับ) → แจกรางวัลเหรียญ → เปิดหน้าต่าง **เลือกกลุ่มดาวผู้สนับสนุน (Sponsor Selection)** เลือก 1 ใน 3 กลุ่มดาว (หรือปฏิเสธเพื่อรับ +300 เหรียญ) → แสดงหน้า **สรุปผลบทละครที่ 1** (Attribute ที่สุ่มได้, เส้นทางที่เลือก, กลุ่มดาว, เหรียญสะสม, Perfect Dodge, เวลา) พร้อมปุ่ม **เล่นใหม่ (สุ่ม Attribute ใหม่)**
